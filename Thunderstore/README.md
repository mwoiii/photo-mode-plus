# PhotoModePlus

PhotoModePlus is a continuation of the PhotoMode mods, originally made by CWMlolzlz. In addition to fixing numerous issues (see changelog), this iteration of the mod provides some additional functionalities.

# Controls

The basics of camera movement and rotation use your configured RoR2 keybinds. The majority of additional keybinds are configurable, with support for Risk of Options.

### Defaults

W/A/S/D - Forwards/Left/Backwards/Right

E/Q - Up/Down

L.Ctrl - Move faster

L.Alt - Move slower

Up Arrow - Increase base camera speed

Down Arrow - Decrease base camera speed

Right Arrow - Physics update step

Tab - Toggle free cursor

Hold MMB + Slide left/right - Roll camera
